# Review model

Varje granskning ska:

- inventera underlag först,
- modellera relevanta trust boundaries och dataflöden,
- välja relevanta profiler,
- prioritera säkerhetskritiska delar,
- kräva evidens för konkreta fynd,
- skilja severity från confidence,
- redovisa coverage,
- rekommendera proportionerlig fortsatt granskning.
