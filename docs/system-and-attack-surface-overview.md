# System-, deployment-, integrations- och attackyteöversikt

Steg 22 flyttar systemförståelsen framåt i rapporten.

## Ny rapportordning
1. Sammanfattning
2. Systemöversikt
3. Analyserade säkerhetsrelevanta flöden och attackytor
4. Scope
5. Arkitekturell säkerhetsbild
6. Fynd
7. Coverage och rekommendationer

## Systemöversikten
Kan visa verifierade huvudkomponenter, tekniker, ansvar, deploymentenheter, aktörer, externa system och integrationer.

## Säkerhetsflöden
Varje analyserat flöde anger flödet, vad som granskades, status och vid behov evidensgrund. Flöden skapas endast när de stöds av faktiskt material/trust boundaries/coverage. De skrivs defensivt och ska inte innehålla exploateringssteg.
