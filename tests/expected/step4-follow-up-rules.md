# Expected properties – Step 4

A compliant review must:

- separate severity from confidence,
- keep `review-point` separate from confirmed/probable vulnerability counts,
- avoid inferring missing controls solely from absence of annotations/patterns,
- consolidate observations that share a root cause,
- select the least extensive follow-up activity that sufficiently reduces important uncertainty,
- justify penetration-test recommendations,
- allow a justified conclusion that no additional deep manual review is necessary.
