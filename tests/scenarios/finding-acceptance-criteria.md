# Acceptance criteria per fynd

## Class
recommendation

## Tags
reporting, developer, remediation

## Input
Ett verifierat fynd ska lämnas över till ett utvecklingsteam.

## Expected
Fyndet ska ange berörda komponenter och ett defensivt acceptance criterion som gör åtgärden verifierbart klar utan exploateringsrecept.

Informationen ska härledas från faktiska fynd, coverage, systembild och follow-up. Rapporten får inte fylla luckor med antaganden och defensiv rapporteringsnivå ska bibehållas.
