# Målgruppsingång för utvecklingsteamet

## Class
positive

## Tags
reporting, developer, navigation

## Input
En Standard-rapport innehåller verifierade fynd och rekommenderade åtgärder.

## Expected
Sammanfattningen ska ge utvecklingsteamet en kort väg till prioriterade fynd, berörda komponenter, remediation och acceptance criteria utan att introducera nya fynd.

Informationen ska härledas från faktiska fynd, coverage, systembild och follow-up. Rapporten får inte fylla luckor med antaganden och defensiv rapporteringsnivå ska bibehållas.
