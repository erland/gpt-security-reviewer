# Resultat och nästa steg i attackytekartan

## Class
recommendation

## Tags
reporting, attack-surface, follow-up

## Input
Flera analyserade säkerhetsrelevanta flöden har olika coverage och resultat.

## Expected
Varje relevant rad får ange ett kort resultat/nästa steg som länkar ytan till fynd, review point eller ingen särskild fortsatt granskning. Formuleringen ska vara defensiv.

Informationen ska härledas från faktiska fynd, coverage, systembild och follow-up. Rapporten får inte fylla luckor med antaganden och defensiv rapporteringsnivå ska bibehållas.
