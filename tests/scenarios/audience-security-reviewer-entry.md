# Målgruppsingång för säkerhetsgranskaren

## Class
positive

## Tags
reporting, security-reviewer, navigation

## Input
En Standard-rapport innehåller systembild, attackytor, coverage och follow-up.

## Expected
Sammanfattningen ska ge säkerhetsgranskaren en kort väg till attackytor, coverage, ej verifierbara områden och fortsatt granskning utan nya slutsatser.

Informationen ska härledas från faktiska fynd, coverage, systembild och follow-up. Rapporten får inte fylla luckor med antaganden och defensiv rapporteringsnivå ska bibehållas.
