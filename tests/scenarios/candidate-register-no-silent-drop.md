# Kandidat får inte försvinna tyst

## Class
recommendation

## Tags
- candidate-register
- consistency

## Input
Ett riskpass identifierar tre kandidater: stale authorization, Git timeout och klientdistribuerad staging capability. Challenge-passet fokuserar främst på stale authorization.

## Expected
Alla tre kandidater ska finnas kvar i kandidatregistret till adjudicering. Ingen kandidat får utelämnas bara för att ett annat fynd prioriteras högre. Varje kandidat får slutlig disposition eller explicit merged/dismissed/coverage-gap med skäl.
