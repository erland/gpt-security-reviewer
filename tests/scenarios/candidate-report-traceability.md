# Rapportfynd måste kunna spåras till kandidat

## Class
recommendation

## Tags
- candidate-register
- traceability

## Input
Slutrapporten innehåller fynd SEC-01 och SEC-02.

## Expected
Varje rapportfynd ska mappas från minst en kandidat med finding_id. Coverage gate ska blockera leverans om ett rapportfynd saknar kandidatspårning.
