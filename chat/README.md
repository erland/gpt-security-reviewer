# Chat-distribution

Denna katalog definierar innehållet i den kompakta Chat ZIP-distributionen.

Chat ZIP ska inte innehålla:
- GitHub Actions,
- utvecklingsplan,
- tests,
- builders,
- interna utvecklingsdokument,
- dist-katalogen.

Chat ZIP ska innehålla:
- `START-HERE.md`,
- runtime-instruktioner,
- relevanta knowledge-profiler,
- schemas,
- versions- och manifestmetadata.
